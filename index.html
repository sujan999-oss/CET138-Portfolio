01 / CONCEPTS

What is Full Stack Development?

Full stack development involves building both the client-facing interface (frontend) and the server-side application (backend). The frontend renders content and handles user interaction. The backend processes requests, applies business rules and accesses data stored in a database. They commonly communicate through HTTP APIs that exchange JSON.

HTML · CSS · JavaScript
⇄ HTTP / JSON

API · Business logic
⇄ Queries

Persistent records

Example data flow: A user submits a login form → JavaScript sends the request → a server validates the credentials against stored user information → the server returns a response → the browser displays the result. Passwords should be securely hashed and authentication handled on the server.

Scope of this demonstration: This portfolio is a frontend prototype. It explains the backend and database but does not claim to implement a live server or database.

02 / STRUCTURE

HTML: Giving Content Meaning

HyperText Markup Language defines the structure and semantics of a webpage. Semantic elements such as <header>, <main>, <section> and <footer> help browsers and assistive technologies understand the page. Labels connect form inputs to their descriptions.

Working example: Contact form

Example source

<form>
  <label for="email">Email</label>
  <input id="email" type="email"
         required>
  <button type="submit">Send</button>
</form>

The for attribute links the label to the input, type="email" enables email-format validation and required prevents an empty field. The live form uses JavaScript to display validation feedback; it does not send or store messages.

03 / PRESENTATION

CSS: Styling and Layout

Cascading Style Sheets control visual presentation, including typography, spacing, color, layout and responsive behavior. A selector targets elements, while declarations set properties. The box model includes content, padding, borders and margins.

Working example: Theme switcher

Responsive card

This card changes appearance using a CSS class.

CSS transitions 
.theme-card {
  padding: 1.5rem;
  border-radius: 1rem;
  transition: all .25s ease;
}
.theme-demo.dark .theme-card {
  background: #18263d;
  color: white;
}

CSS class selectors apply styles. JavaScript toggles the dark class, and the transition smooths the change. Media queries elsewhere in this stylesheet adjust layout for small screens.

05 / INTERACTIVITY

JavaScript: Behavior and Interaction

JavaScript adds behavior to a webpage. It uses variables to hold values, functions to organize logic, event listeners to respond to actions, and DOM methods to update visible content. This quiz demonstrates all four concepts and uses an array of question objects.

Mini knowledge quizQuestion 1 of 4

How it works

button.addEventListener('click', () => {
  score += isCorrect ? 1 : 0;
  feedback.textContent = isCorrect
    ? 'Correct!' : 'Try again next time.';
});

An event listener reacts to a click, a conditional expression checks the answer, and textContent updates the page without reloading. The full working logic is in script.js.

LEARNING REFLECTION

Putting It All Together

Building this demonstration shows how the technologies complement one another: HTML provides meaningful structure, CSS controls appearance, Bootstrap accelerates responsive layout, and JavaScript handles interaction. A complete production application would also need a backend API, a database, server-side validation, security controls, and deployment.

Next steps: Build a small API, connect persistent storage, add automated tests, and evaluate accessibility with keyboard and screen-reader testing.
